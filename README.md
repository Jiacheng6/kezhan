# 学习通助手 0.3.0 · Windows 桌面版

独立桌面窗口，提供课程清单、课程范围选择、视频播放、千问答题、待审队列、实时日志和断点续跑。
发布版本自带运行环境，接收方不需要安装 Node.js、npm 或编辑配置文件。

## 发给别人使用

软件包与更新清单使用独立的下载仓库：[GitHub Releases](https://github.com/Jiacheng6/xuexitong-assistant-releases/releases/latest)。首次发布完成后该入口才可用，源码仓库保持私有。

构建产物位于 `dist/`：

| 文件 | 使用方式 |
|---|---|
| `XuexitongAssistant-0.3.0-Setup.exe` | 安装版，安装后从桌面或开始菜单打开 |
| `XuexitongAssistant-0.3.0-win-x64.zip` | 免安装版，完整解压后双击「学习通助手.exe」 |

支持 Windows 10 / 11 的 x64 系统，需要已安装 Microsoft Edge，使用在线课程与千问需要联网。
首次使用在软件的专用浏览器中登录自己的学习通和千问账号。
完整操作步骤见 [使用说明](使用说明.md)。不要分享开发目录、旧发布版.zip或个人数据目录。

## 软件更新与窗口控制

### 内置更新

0.3.0 新增「检查更新」入口：检查新版 → 下载 → 保存并安装。下载时任务继续运行；只有用户点击安装并确认后，软件才保存数据、退出并启动安装器。普通关闭软件不会自动安装已下载的更新。下载文件由更新组件校验，失败时阻止安装并允许重试。

从旧版首次升级到 0.3.0 需要手动运行一次安装包。后续升级可在软件内完成。免安装版也可检查、下载新版，安装前会说明将切换为安装版；使用同一个 Windows 用户数据目录，不搬移或分享登录数据。

安装前会在用户数据目录的 `updates/backups/` 备份设置、进度、课程选择和课程报告。浏览器登录数据保留原位；退出时等待浏览器完成会话保存。平台主动使登录失效时仍需重新登录。启动界面自动读取已有课程清单，课程新增或需要刷新状态时才重新侦察。

更新源固定为 `Jiacheng6/xuexitong-assistant-releases`，只发布安装包、ZIP、`latest.yml`、安装包 `.blockmap` 和校验清单。发布时先上传全部附件，核对后再公开 Release；不能只替换更新清单。源码、用户数据和发布凭据不进入下载仓库。

### 窗口操作

- 主界面在独立桌面窗口中打开，保留托盘入口。
- 软件提供浏览器「显示」「隐藏」按钮。隐藏只改变窗口可见性，任务继续运行。
- 专用浏览器窗口的关闭入口被禁用，任务通过软件内「停止」按钮控制。
- 关闭主窗口会让用户选择「隐藏到托盘，继续运行」「停止任务并退出」「取消」。
- 双击托盘图标恢复窗口。退出会请求停止、保留进度，并关闭本软件的专用浏览器。
- 启动软件不会自动执行课程任务。验证码、账号过期等问题由用户处理。

## 简答题草稿

简答、论述和分析题使用独立提问词，默认自动填写千问返回的正文草稿。支持 UEditor、普通文本框、可编辑区域与同源 iframe；填写后回读编辑器正文和表单存储值。已有答案会保留，无法作答、空正文、编辑器未就绪或校验失败则转人工。

含简答题的整份作业始终等待人工确认，即使提交模式设为自动也不会自动交卷。可在「待审队列」编辑正文，点「保存并填入」替换该题页面草稿，再核对后提交。修改前请先停止运行中的任务。设置中可关闭「简答题自动填写草稿」，高级设置可修改简答提问词。填空题仍由人工处理。

## 数据与隐私

桌面版将登录状态、设置、进度、课程清单、截图和日志保存在：

`%APPDATA%\XuexitongAssistant`

安装版与免安装版共享同一 Windows 用户的数据目录，升级或移动软件目录不会清除数据。
点击软件内「数据与日志」可打开该目录。卸载默认保留数据。

发布包采用文件白名单，只携带程序和运行依赖，不包含开发者的浏览器配置、登录态、课程报告、进度、日志或题目截图。
旧源码版数据不会自动迁移。源代码 CLI 仍默认使用项目目录的数据，避免修改原有运行记录。

## 开发与构建

构建机使用 Node.js 22.12+（建议 24 LTS）、npm、Windows 自带的 .NET Framework 编译器。
Electron 与打包器版本已锁定在 package-lock.json。
打包使用项目 `node_modules/electron/dist` 中已安装的运行环境，避免每次构建重复下载和校验 Electron。

```powershell
npm ci
npm run build:native
npm start
```

生成两种发布包：

```powershell
npm run build
node tools/build/verify-release.mjs
powershell -NoProfile -File tools/test/test-packaged-receiver.ps1
```

离线回归测试（使用隔离数据目录，不连接账号）：

```powershell
npm test
```

桌面与浏览器窗口测试（空浏览器配置，只访问测试页）：

```powershell
npm run build:native
node tools/test/test-desktop-e2e.mjs
node tools/test/test-essay-editor.mjs
```

保留原命令行入口：

```powershell
npm run start:service
```

## 结构

- `desktop/main.cjs`：独立窗口、托盘、关闭选择、单实例与后台进程生命周期。
- `desktop/preload.cjs`：隔离的桌面操作接口。
- `desktop/native/BrowserWindowControl.cs`：按浏览器进程管理窗口显示、隐藏和关闭入口。
- `src/`：课程、答题、状态、本地服务与界面。
- `tools/build/`：窗口组件编译、图标生成与发布检查。
- `tools/test/`：离线回归与桌面测试。
- `docs/开发说明.md`：通用开发说明；启动与打包以本 README 为准。

- 0.3.0：内置检查更新、手动下载与确认安装；安装前保存退出和数据备份，校验失败阻止安装；启动自动读取已有课程清单。

- 0.2.2：新增简答题自动填写、正文回读验证、待审队列正文编辑；含简答题的作业不自动提交，已有答案不自动覆盖。
- 0.2.2：选择题填写必须与回读选项完全一致，作业题目全部处理完成后才允许自动提交。

- 用户数据与安装目录分离，避免安装目录写权限不足。
- 稀疏千问设置完整合并默认值，避免改一项后丢失其余默认配置。
- 进度写入失败会向调用方报错；损坏状态文件不会被静默覆盖。
- 修复退出收尾中变量名错误，支持桌面消息触发有序退出。
- 浏览器启动失败时仍显示界面和错误信息；断开连接后显示恢复提示。
- 浏览器调试端口由桌面端分配，避免误接管固定端口上的其他实例。
- 概览和课程页的开始、停止按钮同步更新；读取课程时可以请求停止，并保留旧清单。
- 本地服务处理错误 URL、文件目录边界、百分号路径、跨站请求和重启时监听器释放。
- 0.2.1：题目截图改为直接捕获区域，隐藏浏览器时不依赖元素稳定帧；在空 iframe 中验证了内容更新与像素一致性。
- 0.2.1：停止播放后直接保留进度，完成状态核对、截图与千问节流等待可中止，不再额外等数分钟。
- 0.2.1：用 Windows 原生进程句柄监控桌面进程，心跳延迟时继续运行，确认主进程退出后清理后台。
