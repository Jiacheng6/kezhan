# 学习通助手

面向 Windows 的学习通桌面助手，支持课程管理、视频任务、网页版 AI 辅助答题和断点续跑。使用独立软件窗口，可隐藏专用浏览器，让任务继续在后台运行。

**下载后即可使用，无需安装 Node.js、npm 或手动编辑配置文件。**

[下载最新版本](https://github.com/Jiacheng6/xuexitong-assistant-releases/releases/latest) · [完整使用说明](使用说明.md) · [反馈问题](https://github.com/Jiacheng6/xuexitong-assistant/issues)

## 下载与安装

需要 **Windows 10 / 11，64 位（x64）**，已安装 **Microsoft Edge**，并保持网络连接。

当前版本为 **0.4.1**，提供两种使用方式：

## 第一次使用

1. 打开软件，等待专用 Edge 浏览器启动。
2. 在专用浏览器中登录自己的学习通账号，在设置中选择千问、豆包或 DeepSeek，并通过「打开所选 AI 网页」登录自己的 AI 账号。
3. 回到软件，点击「检测登录状态」。
4. 点击「扫描课程」，读取课程清单，选择需要执行的范围，再点击「保存选择」。
5. 点击「开始学习」。需要核对的答案会进入「待审答案」，由你确认后提交。

软件启动后不会自动执行任务。之后打开软件会读取已有课程清单；新增课程或需要刷新平台状态时，再重新扫描课程。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 课程管理 | 读取课程与章节任务，分别显示视频、测验等任务的完成状态及小节完成数 |
| 视频任务 | 播放所选视频任务，记录执行状态 |
| 网页版 AI 辅助答题 | 千问、豆包、DeepSeek 手动切换；处理选择、判断题，支持简答、论述和分析题草稿填写；额度与验证限制以平台提示为准 |
| 待审答案 | 查看需要人工处理的题目，核对答案、修改简答草稿并确认提交 |
| 断点续跑 | 保存设置、课程选择和任务进度，重新启动后继续使用 |
| 后台运行 | 隐藏专用浏览器或将主窗口收起到托盘，任务继续执行 |
| 内置更新 | 启动检查新版并展示更新内容，用户选择下载，确认后保存数据并启动安装程序 |

默认采用人工确认提交。开启自动提交后，也只有整份作业的题目全部处理完成、答案均通过可靠性检查时才会自动提交。

**含简答题的作业始终需要人工确认，填空题需人工填写。** 简答草稿填写后会回读验证，已有答案不会自动覆盖。修改草稿前，请停止当前任务，再到「待审答案」编辑正文，点击「保存并填入」，核对后提交。该按钮只填写草稿。

软件不处理考试，不绕过验证码，不伪造视频播放进度。账号登录过期、验证码和需要人工处理的页面仍由用户操作。

## 隐藏、停止与退出

- **隐藏浏览器**：只收起本软件的专用浏览器窗口，任务继续运行；点击「显示浏览器」可恢复。
- **停止任务**：在软件内点击「停止」。专用浏览器自身的关闭入口被禁用，任务由助手控制。
- **关闭主窗口**：会提示选择「隐藏到托盘，继续运行」「停止任务并退出」或「取消」。
- **恢复窗口**：双击右下角托盘图标。

退出会保存进度并关闭专用浏览器。电脑休眠、断网或浏览器被系统强制结束时，任务可能中断，已保存的数据会保留。

## 软件更新

0.4.1 起，每次启动会自动检查一次更新，发现新版弹窗展示版本与更新内容。可点击「下载新版」或「稍后」，没有新版或检查失败时不会弹窗。左侧「检查更新」仍可手动使用。

**检查更新 → 下载新版 → 保存并安装 → 确认安装**

下载期间任务可以继续运行。确认安装后，软件保存数据、停止任务并退出，再打开安装程序；普通退出不会自动安装已下载的更新。

- **从 0.2.x 升级**：正常退出旧版，手动运行一次 0.4.1 安装包，之后即可使用内置更新。
- **从 0.3.x / 0.4.0 升级**：先手动点击一次「检查更新」，安装 0.4.1 后即可获得启动自动提醒。
- **安装版更新**：同一 Windows 用户下继续使用原有登录状态、设置、课程选择和进度，更新后不必重新扫描课程。
- **免安装版更新**：内置安装会提示切换为安装版，并继续读取同一数据目录。也可下载新版 ZIP，完整解压到新文件夹后启动。

更新文件会经过校验，校验失败时阻止安装。安装前会备份设置、进度、课程选择和课程报告。平台主动使登录失效时，仍需重新登录。

## 数据保存在哪里

安装版与免安装版共享同一 Windows 用户的数据目录：

```text
%APPDATA%\XuexitongAssistant
```

点击软件内「数据与日志」即可打开。移动软件文件夹、更新软件或正常卸载默认不会清除这些数据；更新前的备份位于该目录的 `updates/backups/`。

数据目录包含个人登录状态、课程信息、进度、答题记录和日志，请保留在自己的电脑上。发布包只包含程序及运行依赖，不包含开发者的账号数据。旧源码版的数据不会自动迁移。

## 常见问题

**更新后需要重新登录或扫描课程吗？**

同一 Windows 用户下，桌面版会继续读取原有数据，已有课程清单会自动加载。账号会话失效时需重新登录；课程有变化时才需要重新扫描课程。

**隐藏窗口后，任务还会运行吗？**

会。隐藏浏览器或隐藏到托盘不会停止任务；需要停止时，请使用软件内的「停止」按钮。

**简答题为什么没有自动提交？**

简答题只自动填写草稿，整份作业都需要人工核对后提交。填写失败或已有答案时，会转入待审答案。

**启动失败怎么办？**

先确认已安装 Edge，并已完整解压免安装包。可在软件内点击「重启服务」，通过「数据与日志」查看 `logs/desktop.log`。反馈问题时请提供版本、复现步骤和错误提示，并先移除日志中的个人信息。

## 源码运行与构建

以下步骤供开发者使用。直接使用软件请下载上面的发布包。

在 Windows 上准备 Node.js 22.12 或更高版本、npm，以及 Windows 自带的 .NET Framework 编译器：

```powershell
npm ci
npm --prefix tools/ui/course-archive ci --ignore-scripts
npm run build:archive
npm run build:native
npm start
```

设计预览可运行 `npm run preview:ui`：打开实际桌面界面，使用隔离的虚构课程与模拟任务状态，不读写真实账号数据。

测试和生成安装版、免安装版：

```powershell
npm test
npm run build
node tools/build/verify-release.mjs
powershell -NoProfile -File tools/test/test-packaged-receiver.ps1
```

构建产物保存在 `dist/`。保留命令行服务入口 `npm run start:service`；该入口默认使用项目目录的数据，与桌面版的数据位置不同。

课程档案使用本机清单与逐项完成状态：悬停轻抬、点击竖直抽取，由镜头转向正面；确认课程名后显示章节，再进入工作台选择范围。三维核心与模型基于 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)（MIT）；可编辑源码位于 `tools/ui/course-archive/`，本地打包资源和许可位于 `src/ui/library/archive/`。没有个人课程数据内置其中。侧栏可切换经典工作台外观。

源码主要位于 `src/`，桌面窗口与更新模块位于 `desktop/`，构建和测试工具位于 `tools/`。更多约定见 [开发说明](docs/开发说明.md)。提交前请运行隐私检查，勿提交账号配置、浏览器数据、课程报告或运行日志。
