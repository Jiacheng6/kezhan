# 学习通助手 · 课程档案视图

基于 LBEILC/RhineLabUI 提交 12cc5e4013acb9408f753ff71de6b8492299b7c8，按 MIT 许可使用（见 LICENSE）。按最终选择恢复原版模型、表面材质、灯光、阴影与景深；课程标签、预览、任务详情和工作台桥接使用本机数据。

悬停轻抬、竖直抽取、镜头转向、波浪、惯性拖动与无限循环保持原版逻辑。浏览不会启动或提交课程任务。退出档案页或隐藏窗口后暂停绘制。

构建：本目录 npm ci --ignore-scripts，项目根目录 npm run build:archive。运行版复制原始 archive-cassette.glb，不删减模型；探索过的文件夹生成脚本不参与当前构建。

性能优化：本地半浮点环境光预计算、加载页预编译并试绘材质与完整后处理、复用实例缓冲及深度数据。标准画质保持原始参数；流畅优先由用户手动选择。环境光可通过 node tools/preview/bake-archive-environment.mjs 重新生成。

软件资源不内置个人课程；课程数据来自宿主工作台，保存在本机。模型或显卡不可用时仍可直接进入工作台。经典工作台外观保留。
