# 课程档案与工作台

采用档案控制台方向：暖灰色纸面、炭黑任务区、少量琥珀色提示。目标是让课程浏览与实际任务控制连贯，同时保持课程范围、进度和停止入口清晰。深色监控台和阅读手册曾作为方向备选；这里沿用用户确认的三维档案视觉。

首页按最终选择恢复 RhineLabUI 原版档案模型、阵列材质、灯光、阴影和景深，不使用探索过的纸页、自绘文件夹或冷蓝替代样式。课程名称替换到标签上，课程数据由本机清单提供。悬停轻抬、点击竖直抽取、相机转向正面，确认后再显示章节与各项任务状态。无限循环和工作台入口保留。性能优化限于资源预计算、材质预热、缓冲复用和离屏暂停，避免改变标准画质的视觉效果。

工作台把本次任务作为主操作区，用单独的进度条显示运行状态；其余数量、课程一览和连接状态降低视觉权重。避免无用大标题和营销文案。列表、设置和待审答案沿用现有功能及事件绑定。经典样式保留在 `src/ui/style.css`，新外观以独立样式叠加，侧栏可随时切换。

此次按用户确认恢复完整工作台：学习概览、三列选课、待审、记录与设置均有直接导航。档案阵列首页保留；选课页顶部提供三列/树状切换，保存视图偏好且不改变任务勾选。播放偏好在概览右栏提示，完整设置位于偏好设置。沿用炭黑主操作区、暖灰底与琥珀提示，不另起视觉方向。截图按主次层级、操作可发现性、文字对比、键盘焦点和窄窗溢出自查。

网页访问改为固定顶栏入口，档案页提供同名入口；列表优先列出当前任务，页面切换不导航或重载。进度使用琥珀色刻度轨道和等宽百分比，主轨道反映当前任务，细轨道反映整批已完成数。视频附播放时长与实际速度，测验按已处理题数计量；准备、扫描与平台核对有独立文字状态。三列右栏使用紧凑排布，宽版树状视图横向展开；内置网页保留精简轨道。动画只用于实际进度过渡及未知状态提示，遵循系统/本机减少动态偏好。截图自查覆盖运行、核对、答题、停止、网页选择及窄窗，删去重复的任务名称与多余留白。

所有实际任务操作继续通过原来的工作台执行，不因浏览课程而启动或提交。往返不丢失未保存的勾选。离开三维页或隐藏软件窗口后暂停渲染，不停止学习任务。减少动态遵循系统或本机偏好。

使用隔离演示数据在 Electron 中截图自查，覆盖阵列、悬停、课程预览、详情、运行中、课程树、待审答案、设置和窄窗口。功能回归命令：
