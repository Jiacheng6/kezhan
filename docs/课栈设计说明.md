# 课栈 · 档案工作台

服务于同时使用多个课程平台的学生，首先解决选课、查看进度、开始与停止学习。视觉沿用档案隐喻：启动页保留三维阵列，工作台像索引台，冷灰底、深绿色控制区、细线分隔；正文使用系统中文字体，索引使用等宽数字。

首页以课程索引为主体，下面是统计与本次学习控制；连接、播放偏好、待审提示在侧栏。三列选课保留课程、任务、执行范围，树状视图与批量选择仍可使用。切换页面仅用轻微位移与透明度过渡，尊重减少动态偏好。

避免纸张黄底、巨大欢迎语、重复状态卡与争夺注意力的装饰。保留经典界面入口。首版覆盖概览、三列选课及共同导航，不重做已有三维模型。

默认“全部平台”，可筛选学习通、智慧树及后续平台。课程、三列选课、树状清单、待审题组和三维档案分别标明来源。筛选只改变显示，不取消其他平台的勾选。

顶部独立平台控制区在各页面均可见，显示两平台各自的任务数量与进度；可同时开始，分别停止。多平台模式隐藏重复的大块运行面板。原选课页的“停止全部任务”仍会停止所有平台。

智慧树入口使用软件内网页，登录后可从共享课主页逐课扫描视频和章节测验目录。扫描页不播放媒体。人工验证及本人承诺书保留给用户，扫描未完成不覆盖原清单；翻转课等未适配入口明确列为跳过。

两个平台的课程独立执行，共用 AI 网页则使用一个请求队列。当前请求拥有上传、发送、回答读取及人工验证的完整周期，等本题结束再放行下一题；待处理平台显示“等待共用 AI”。排队请求可独立取消，取消当前平台只停止其已发起的 AI 生成，完成清理后再交给另一平台。

智慧树章节测验截图、原生点选、保存及刷新回读后进入待审，不算任务点完成；待审恢复按稳定选项标识映射，正式提交为独立操作。试卷地址的 hash 也参与身份核对。手动提交后在同一试卷确认成绩才能清除待审。

原学习通课程、任务标识及存储位置保持兼容，智慧树使用独立命名空间和课程目录文件。不更改安装文件名、appId、更新地址及 XuexitongAssistant 数据目录；正式打包改名需另行验证安装升级迁移。

验证：已有 Electron 演示窗口检查了默认汇总、来源标签、筛选保留全部勾选、平台独立启停请求、档案来源及窄窗口。新排队提示已在演示工作台读取确认；隐藏/遮挡窗口的完整新截图流程未跑完，不作为视觉验收通过。
