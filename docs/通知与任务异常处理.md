# 通知与任务异常处理

适用于 0.5.2 及以上版本。

## 提醒入口

Windows 原生通知会在任务后台运行时提醒。点击可回到软件并打开原 AI 页面、待审答案、运行记录或更新面板。不会自动通过验证、恢复任务或提交答案。

软件内的提示沿用关闭确认及首次引导的弹窗样式。工作台和档案首页均有「通知」入口；未读提醒保存在本机，关闭系统弹窗、选择「稍后处理」或重新打开软件不会清空。

Windows 系统通知采用系统样式，显示受 Windows 通知权限及勿扰设置控制。软件另保留未读提示、通知记录及重要事件的任务栏闪烁；不会为弹窗强行抢走焦点。

## 关键事件覆盖

| 场景 | 提醒及后续行为 |
| --- | --- |
| AI 人工验证、登录失效、限流、草稿或附件冲突、仍在回答 | 暂停整批、保留当前作业与未处理题目，点击打开原 AI 页面 |
| 视频弹题或其他任务需人工处理 | 暂停整批，显示未完成，转待人工并提醒 |
| 任务重试后仍失败、连续失败、批次异常 | 明确提醒，失败和人工处理不计入已完成 |
| 答案待确认、批次结束仍有待处理项 | 待审单独计数，点击进入待审答案 |
| 批次完成、按用户要求停止 | 分别显示完成和已停止，不混为同一种结果 |
| 学习通登录失效 | 提示重新登录，点击打开学习通 |
| 课程扫描完成、失败、停止 | 分别通知，不将失败扫描提示为成功 |
| 人工提交成功、失败或未确认 | 以平台确认结果为准；未确认时保留记录 |
| 更新可用、下载并校验完成、更新失败 | 点击查看更新面板，不自动安装 |
| 后台或界面服务异常 | Windows 提醒及通知历史保留，提示查看软件 |

上述共 23 类通知。重复事件在未读期间合并，正常进度刷新不弹通知。Windows 通知不包含课程名称、题目正文、AI 答案或账号信息。

## 首题失败与待审修复

验证码、未登录或额度限制不会再被作业收尾流程覆盖成「成功」。即使第一题失败，当前题及尚未处理的题目也会写入待审，保留题型和作业定位；AI 调用错误不会当作简答正文填入。待审与平台确认完成分别计数。

升级不会自动修改历史待审记录、补交作业或开始学习。

## 选课范围

三列选课新增「取消全选」和逐项「仅选此项」。课程复选框控制整门课，部分选中时显示半选状态；先取消全选，再勾选不同课程即可组合本次学习范围。搜索、筛选及浏览课程不会自动取消其他勾选，开始按钮始终显示明确的任务数量。

启动前保存并发送本次任务标识及身份，后台与保存范围核对一致才执行；未勾选的任务不进入执行清单，也不登记为跳过或待人工。保存途中改变选择、选课文件损坏或任务身份变化时取消启动，不回退成全选。视频弹窗未解决时暂停整批，不继续下一个视频。
