# 学习通助手 0.5.3

## 本次更新

- 新增首次使用向导、内置网页工作区与课程档案首页，保留三列选课和树状列表。
- 改进课程分组、筛选、选择方案和章节完成状态展示；任务进度可在工作台及网页切换时查看。
- 视频弹窗题日志明确显示 AI 图片题是否发送、是否收到回答及失败原因。低可靠答案仍会停止在选择前，避免误选或误提交。
- 视频弹窗题失败时保留学习通页面，并在“待审答案”空队列中展示保留页面入口；人工处理记录也会指向“需要你处理”。
- 改进软件内网页切换、退出确认、任务恢复与更新提示。

## 升级说明

安装版更新会保留课程清单、选择方案、任务进度与网页登录数据。更新不会自动开始学习或提交答案。首次从旧版内置浏览器切换时，可能需要在软件内重新登录学习通和所选 AI 网页。

视频弹窗题只有在 AI 答案可靠且选项回读校验通过时才会自动选择并提交；AI 无回答或答案不可靠时，页面会保留供人工处理。

## 下载

Windows 10 / 11，64 位。提供安装版和免安装 ZIP，也可在软件内检查更新后下载并安装。
