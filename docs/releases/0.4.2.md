# 学习通助手 0.4.2

## 本次更新

- 作业页关闭后，可在「待审答案」点击「重新打开并恢复」，重新打开对应作业并恢复已保存的选择答案和简答草稿；重启软件后也保留恢复入口。
- 恢复时核对作业、答题记录和题目标识，兼容题目顺序变化。题目缺失、作业变化或答案未填全时，保留待审记录并提示人工核对。
- 修改简答题时先保存草稿；网页恢复或填写失败会明确提示，不再误报已填入。
- 提交后等待平台确认，只有确认成功才移除待审记录并标记完成。结果不明确时保留记录，避免重复提交；批量提交分别报告成功和失败。
- 同一组作业的恢复、编辑和提交操作互斥，避免连续点击产生重复操作。

## 下载与升级

- Windows 10 / 11，64 位；需要 Microsoft Edge。
- 安装版：XuexitongAssistant-0.4.2-Setup.exe。
- 免安装版：完整解压 XuexitongAssistant-0.4.2-win-x64.zip 后打开「学习通助手.exe」。
- 0.4.1 用户启动时会收到新版提示，也可手动点击「检查更新」；0.3.x / 0.4.0 用户请手动检查更新。下载后由用户确认安装，普通退出不会自动安装。
- 同一 Windows 用户下继续读取已有登录、设置、课程清单和进度；平台登录过期时仍需重新登录。

恢复仅使用本机已保存的答案与草稿；缺少定位信息或答案的旧记录仍需人工处理。打开软件不会自动开始课程任务或提交待审作业。

发布包不包含个人账号、课程数据或登录 Cookie。
