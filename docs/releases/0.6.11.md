# 课栈 0.6.11

这一版集中修"跑一段时间就莫名暂停 / 重试也不管用"的问题。根因是三类**环境性失败**被当成任务真失败，以及 AI 通道被页面状态卡死。

- 失败分级：截图超时、字体未就绪、视频元数据晚到、AI 草稿残留这类"换个状态就能过"的失败不再计入"连续真失败"；连续 3 个真失败才停批，环境性失败放宽到 5 次。
- 暂停不再莫名：暂停原因会写清是哪几题、卡在什么类别，可直接照着处理。
- 千问页面有两个装饰元素带 loading 类名，旧逻辑把它当成"AI 一直在回答"，导致**每次提问都被拒绝**。已改为"有实际尺寸且在回答区内"才算在生成。
- AI 正在回答上一条时先等它答完（默认最多 60 秒），不再把整个批次暂停；只把该任务记为待续跑。
- 题目字体改为**主动加载**（原来只被动检查，内置网页在后台时字体会一直不来），所有 AI 通道共用的成像环节不再假失败。
- 区域截图增加三级降级（元素 → 裁剪 → 整页），不再让单张截图默认等 30 秒。
- 视频时长读不到时先重新触发加载一次，并把错误码写进提示（媒体源问题与网络问题可区分）。
- API 通道兼容更多返回形状（内容数组、旧版 text、Responses 风格、推理模型正文），空回答时提示里会带 finish_reason，便于判断是被截断、被拦截还是模型不支持图片。
- 新增设置项：连续多少个真失败停批、连续多少次环境性失败停批、AI 忙时最多等多久。

更新会保留登录、课程与进度。也可从国内下载页下载安装包，正常退出软件后覆盖安装。
