# 学习通助手 0.5.0

## 本次更新

- 学习通、AI 和课程网页全部在软件内打开；新增固定「查看网页」入口，可直接查看当前任务，无需外部浏览器。
- 默认先显示档案阵列首页，恢复完整工作台并保留三列／树状选课；新增琥珀色任务进度条，显示播放时间、实际速度和答题进度。
- 支持优先选择课程自带倍速，不支持时回到 1×；可在 90% 时先核对平台，未完成就从当前位置继续播到片尾。

## 升级说明

首次从旧版外部浏览器切换到内置网页，需要重新登录学习通和所用 AI 一次。课程清单、设置、选课方案及任务进度保留，无需因此重新扫描课程。后续更新继续保存内置网页登录数据；平台登录过期时仍需重新登录。

视频完成状态以平台实际确认为准。平台人工验证和需要人工处理的题目仍由用户操作；查看网页、选课及启动软件都不会自动开始任务或提交作业。

## 下载

Windows 10 / 11，64 位；桌面版自带网页引擎。

- 安装版：XuexitongAssistant-0.5.0-Setup.exe。
- 免安装版：完整解压 XuexitongAssistant-0.5.0-win-x64.zip 后运行「学习通助手.exe」。

可从旧版「检查更新」下载新版，确认后保存并安装。发布文件不含个人账号、课程数据、登录 Cookie 或本地测试记录。
