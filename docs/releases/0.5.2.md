# 学习通助手 0.5.2

## 本次更新

- 新增 Windows 通知和软件内提醒：验证、登录失效、任务异常、待审及更新等关键情况都会提醒；支持未读记录和点击直达。
- 新增「取消全选」「仅选此项」及课程半选状态，开始按钮显示任务数量；启动前核对本次选课范围。
- 修复 AI 验证失败后继续跳题、误计完成的问题；首题失败也保留待审。视频弹窗未解决时暂停整批，不再继续下一个视频。

## 升级说明

保留课程清单、选课方案、任务进度和内置网页登录数据，无需因升级重新扫描课程。更新不会自动开始学习或提交答案。

Windows 通知采用系统样式，并受系统通知权限及勿扰设置控制；软件内仍保留未读提醒。AI 验证需在软件内的原网页手动完成，处理后重新开始任务。

本版修正后续执行和计数，不会将过去未提交的作业改为已完成，也不会代为补交历史作业。

## 下载

Windows 10 / 11，64 位。提供安装版和免安装 ZIP，也可在软件内检查更新后下载并安装。
