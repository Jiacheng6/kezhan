# 学习通助手 0.4.3

## 本次更新

- 选课、任务进度和开始／停止集中到三栏工作台，常用操作更容易找到。
- 首次使用新增两步向导：登录学习通，选择千问、豆包或 DeepSeek；完成后不再重复提示。
- 关闭窗口弹窗统一风格；更新提示默认只展示三条重点，可展开完整说明。
- 支持快捷选择未完成任务、视频或测验，以及指定节号范围；先预览再应用，可撤销一次修改。
- 可保存、载入和管理选课方案，按学习通账号分别保存；课程变化时提示核对，新任务不会自动加入旧方案。
- 已完成课程默认收起，任务分别显示完成状态；树状视图和档案入口保留在界面中。

## 下载与升级

- Windows 10 / 11，64 位；需要 Microsoft Edge。
- 安装版：XuexitongAssistant-0.4.3-Setup.exe。
- 免安装版：完整解压 XuexitongAssistant-0.4.3-win-x64.zip 后打开「学习通助手.exe」。
- 0.4.1 及以上版本启动时会提示更新，也可在软件中手动检查；较早版本请手动检查更新或下载新版。
- 同一 Windows 用户下继续读取已有登录、设置、课程清单与进度。已有使用记录的用户不会被强制弹出首次向导，可在偏好设置中重新打开。

AI 网页版需使用自己的账号，额度和验证限制以平台提示为准。软件启动、选课和检查更新都不会自动开始任务或提交作业。

发布包不包含个人账号、课程数据或登录 Cookie。
