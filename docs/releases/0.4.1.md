# 学习通助手 0.4.1

## 本次更新

- 启动时自动检查新版。有更新时弹窗展示版本和更新内容，可选择下载或稍后；没有新版或连接失败时不打断使用。
- 下载完成后由用户确认安装，安装前保存进度并备份数据。普通退出不会自动安装。
- 课程及小节分为“待完成”和“已完成”，完成内容默认折叠，可搜索、展开查看。
- 修复扫描前已完成的小节被省略的问题，兼容本机已有的扫描记录；未读全或读取失败的内容不再误判为完成。
- 新增豆包、DeepSeek 网页版 AI 通道，可在设置中与千问手动切换。各通道需登录自己的账号，使用额度以平台提示为准。
- 修复题目截图被无关字体加载阻塞的问题，截图失败时增加一次恢复重试，并明确显示失败阶段。
- 修复快速进入工作台后返回课程档案可能出现三维画面空白的问题。

## 下载与升级

- Windows 10 / 11，64 位；需要 Microsoft Edge。
- 安装版：XuexitongAssistant-0.4.1-Setup.exe。
- 免安装版：完整解压 XuexitongAssistant-0.4.1-win-x64.zip 后打开“学习通助手.exe”。
- 已使用 0.3.x / 0.4.0：先手动点击软件内“检查更新”，下载并安装一次。0.4.1 起每次启动会自动检查并提示新版本。
- 同一 Windows 用户下继续使用已有登录、设置、课程清单和进度；平台登录失效时仍需重新登录。
- 免安装版通过内置安装入口升级时会切换为安装版，继续读取同一本机数据。

发布包不包含个人账号、课程数据或登录 Cookie。打开软件不会自动开始课程任务。
