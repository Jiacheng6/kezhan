# 多渠道与本地更新验收

状态：随 0.6.10 发布。

## 行为

- 默认 CNB 国内源优先；检查失败自动尝试 GitHub。国内源没有新版时也检查备用源，避免两边同步时间差。
- 手动指定渠道后只连接该渠道，选择持久保存在用户数据目录。
- 下载失败可尝试备用源；必须版本、SHA-512 和提供的大小一致。校验失败直接阻止安装，不静默绕过。
- 本地导入使用同版本的安装包和 `release-manifest.json`，校验 SHA-256 后复制到独立缓存；通过仅监听本机、随机路径的临时服务交给原更新器，再做 SHA-512 校验。
- 本地校验文件用于核对完整性，不等同于发布者数字签名。请使用公开发行页提供的配套文件。
- 联网失败时本地入口仍可用。用户取消选文件或安装时不退出软件。正式安装前沿用保存、备份和确认流程。
- 应用不携带 CNB 发布令牌，也不依赖需要登录的最新版本 API。固定 `latest` 标签下的公开附件提供更新清单。

## CNB 后续发布约定

下载仓库：`https://cnb.cool/kezhan-app/kezhan-releases`。

固定更新目录：`https://cnb.cool/kezhan-app/kezhan-releases/-/releases/download/latest/`。

先上传版本化的 EXE、ZIP、blockmap、校验文件和说明，核对公开下载后，再更新 `latest.yml`。清单中的安装包保持相对文件名，使下载留在当前渠道。新版须在两个渠道都准备好并核验后才标为正式可用；下载换源遇到版本或校验值不同会停止下载并提示重新检查。

上传仅使用经过隐私检查的发行文件白名单；不得上传构建日志、浏览器数据、学习记录和本机配置。国内通道已用 0.6.9 完成真实下载验收，正式发布时与 GitHub 一并更新为 0.6.10。
