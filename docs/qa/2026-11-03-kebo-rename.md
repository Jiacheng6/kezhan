# 课泊品牌与升级迁移

本地版本0.6.12，未上传，未安装或替换用户现有0.6.11。

## 新标识

- 品牌：课泊 / Kebo；包名 `kebo`；应用ID `com.kebo.app`。
- 程序/卸载器/快捷方式：`课泊.exe`、`Uninstall 课泊.exe`、课泊。
- 发行文件：`Kebo-0.6.12-Setup.exe`、`Kebo-0.6.12-win-x64.zip`。
- 数据目录：用户应用数据下 `Kebo`；启动环境变量 `KEBO_*`。
- UI偏好和帧间消息前缀 `kebo-`，内部网页标记 `__kebo`。
- `src/ui/kebo.css`、`kebo.js` 替代旧品牌文件；档案前端已从源码重新构建。

## 必要兼容

安装器GUID显式保留 `498a0d80-d4f9-5e0f-b76b-f2eb2460b8bc`，这是原应用ID在electron-builder中派生的GUID。显示名、程序名和新应用ID已更名，但安装注册记录需要连续，避免重复安装和错误更新目录。升级沿用用户原先选择的安装位置，不移动正在使用的程序目录。

首次启动前取得旧目录对应的Electron单实例锁，若旧软件仍在运行，则不复制数据库，交由原实例处理；之后才复制旧配置目录到临时目录，成功后原子改名为Kebo。复制保留Local State、Partitions、加密会话和配置，跳过临时锁/调试端口，不删除旧目录，不覆盖已有新数据。复制失败回退旧数据并提示；数据中的链接停止自动迁移，避免跨目录复制。

旧 `XXT_*` 启动变量仅在兼容边界映射到 `KEBO_*`，新值优先。旧 `xxt-` 外观偏好首次读取时复制到新键，不覆盖已保存的新偏好。离线更新仍接受旧前缀的完整配套安装包；当前发布仓库URL保留，未在本轮修改远端仓库或发布状态。
