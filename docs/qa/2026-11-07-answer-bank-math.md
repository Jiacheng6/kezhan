# 数学题库兼容验收（源码，未发布）

## 改动范围

- 学习通作业和章节测验使用现有题目容器提取入口，保持原始题干和作答身份规则。
- 另行生成题库兼容字符串：图片、音频、iframe 地址和带 TeX annotation 的数学公式，按旧版脚本顺序处理实体、标点和空白。资源 query 参数不清理。
- U+2002 按原版删除，U+3000 不额外删除；题干中的引号和百分号按原版替换。
- 仅在克隆的惰性 DOM 中转换。不会清空勾选、改变编辑器或提交表单。
- 公式题干与图片选项保存内容指纹；草稿恢复时核对公式，选项换序按内容重新定位字母。旧纯文字草稿仍使用原有规则。
- 数学答案严格比对，避免 NFKC 把 x² 与 x2 混为一谈。候选答案不唯一或题干不同仍回退，不凭相似度放行。
- 纯图形 SVG、无 TeX 源码的 MathML、缺失或临时资源地址、过长内联图片等不发查题请求，按用户现有设置交给 AI 或待审。

## 离线浏览器验收

运行 `node tools/test/test-answer-bank-math.mjs`。测试拦截所有网络请求，不使用个人账号和真实题库令牌。

已覆盖：

- 8 种原版字符串样例：TeX、签名图片、无引号图片属性、有界 base64、U+2002、U+3000 与标点、iframe、旧式音频。
- 题型标签排除；提取前后 DOM、表单、已选答案一致。
- 6 种不支持题面安全回退；不同公式不接受，相同图片选项不猜测。
- 3 题模拟整卷：题库回填、独立题数核对、表单回读、仅一次模拟提交，AI 调用为 0。
- 重开后的图片选项换序；题干文字相同但公式图片已换时阻止恢复和提交。

现有题库浏览器回归、待审恢复浏览器回归均通过。完整离线套件初跑时有 7 项受到本机连接和浏览器权限限制；使用正常运行环境及独立数据目录逐项重跑后均通过，未为这些环境限制修改产品代码。语法检查与差异空白检查通过。

## 真实题库查询

本轮授权上限为 3 次，通过独立预览的正常登录与原生题库服务发出，实际使用 3 次，无额外查询。

| 样例 | 接口返回 | 本地核对 |
| --- | --- | --- |
| 图片题干与图片选项 | 候选答案 | 题干一致且唯一映射到选项，通过 |
| 图片题干与文字选项 | 候选答案 | 返回题干少了原题部分字符，拒绝采用，继续按设置回退 |
| 图片判断题 | 候选答案 | 题干一致，明确判断值匹配，通过 |

首个样例发现外层题型标签被带入查询，已修复并用同一份缓存回包重新核对，没有为此再次查题。真实验收为 2/3 可安全映射；这是接口兼容结果，不等于平台判分准确率，也不能外推全题库命中率。

当前真实题面均为图片，带 TeX 源码的公式仅完成离线验收。本轮没有回填、选择或提交真实作业；真实成绩及完整数学作业提交尚未验收。
