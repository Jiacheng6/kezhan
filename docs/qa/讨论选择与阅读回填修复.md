# 讨论选择、阅读预览与判断回填（0.5.16）

- 讨论关闭时显示具体原因和设置入口。保存开关后刷新已有任务的可执行策略，保留选课范围；新解锁的讨论不自动全选。三列选择与树状视图均提供入口。
- 阅读任务按任务点标识定位对应文档，进入实际预览并滚动正文，让平台原生阅读规则处理计分；随后重新读取该附件的完成标记。相邻视频或文档的完成标记不能代替当前附件。没有找到目标或预览不支持时保留人工处理，不冒充“非任务点已完成”。
- 判断题保留实际显示字母与内部 true/false 的关系。AI 回答 A/B 时只按当前页面已验证的对应关系转换，不假定 A 永远代表“对”；缺少映射、字母越界、结论矛盾或存在不确定性时不自动回填。提示词优先要求明确回答对/错。
- 兼容学习通原生 radio/checkbox 表单：从题头读取题型、按真实 input value 点选并回读，不再只支持带 qid 和 span[data] 的布局。
- AI 新会话导航后等待实际编辑器就绪，避免页面尚在加载就误报未登录。豆包虚拟列表中脱离文档节点的比较结果不能作为“出现其他提问”的证据；真正的后续提问仍阻止使用旧回答。
