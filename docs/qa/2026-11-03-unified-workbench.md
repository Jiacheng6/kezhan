# 统一工作台与交互改造

范围：源码 UI；未打包、未上传、未替换安装版。平台学习和提交逻辑未在本次执行。

采用 distinctive-ai-design 和 emil-design-eng。选定方向为精密工作台：档案阵列首页保留，工作台优先展示任务控制，其他页面使用紧凑状态条。配色以中性表面加单一可切换强调色为主。

| Before | After | Why |
| --- | --- | --- |
| 平台操作散布在平台条和维护设置 | 三个平台统一集中在管理平台菜单 | 打开网页、扫描课程入口一致 |
| 所有页面都展示大块运行面板 | 工作台展开，其他板块使用紧凑状态条 | 给选课、待审和设置留出空间 |
| 多平台模式隐藏主要任务面板 | 保留主要控制，显示独立平台运行数量 | 用户能找到停止全部任务 |
| 平台运行但主按钮仍提示开始 | 汇总平台运行状态后更新开始/停止按钮 | 减少重复启动和状态误导 |
| CSS、WAAPI 同时驱动切页 | 由 motion.js 负责 200ms 过渡 | 避免重复动画，支持中断 |
| 主题切换使大量后代控件逐个渐变 | 短暂整页交叉淡化，减少动态时直接切换 | 避免冗余重绘与拖沓 |
| 每次状态更新重建平台筛选按钮 | 筛选值或数量变化时才更新节点 | 保留键盘焦点 |

主要代码：`src/ui/workbench.css`、`theme.css`、`theme.js`、`motion.js`、`kezhan.js`、`app.js`、`index.html`。原 `layout.css`、`palette.css` 文件仍保留，但主页面不再加载，避免主题规则叠加。

验证使用 `tools/preview/workspace.mjs --workbench --multiplatform` 生成的独立演示数据。运行 `node tools/preview/check-workbench.mjs` 可复查：10 组主题、五个页面、主题持久化、平台菜单单次动作、Escape 与焦点恢复、三列/树状选课、1000px 宽度溢出、减少动态效果、档案场景实际加载。截图和证明位于 `.desktop-test/ui-review-1103/`，不随发布上传。

已通过：`check-ui-ids.mjs`（108 项）、`test-multiplatform.mjs`、`test-selection-plan.mjs`、`test-ui-motion.mjs`。动效测试对面板动画的采样移到导航后、第二次交互前，以免 200ms 动画在采样前已结束。

视觉评审采用自查，两轮截图覆盖工作台、三列选课、设置、待审、日志、平台菜单和档案首页。第一轮调整信息层级与主题；第二轮收紧非概览页面的顶部状态区、修正跨平台控制状态。截图已实际打开检查。
