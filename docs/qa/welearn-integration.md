# WeLearn 接入与验收

这是源码开发记录，不代表已发布版本包含本功能。未修改用户安装版，也未打包上传。

## 当前方案（用户最新要求，取代早期 AI 方案）

默认入口已切换到 Auto-WeLearn 接口流程，不再依赖 AI。直接复用上游 `9459bb7fafcd98868f9796d6187afd1d5fe6c049` 的 14 个模块，保留原始 TypeScript、生成的运行文件、GPL-3.0 许可与来源声明。

课栈负责选课范围、会话、停止、提交设置和平台完成回查。每小节等待默认 300 秒，可设 30–900 秒；等待和心跳后提交答案、学时、完成数据。**这是接口上报模式，不等同于真实视频播放。**

人工提交模式只准备和保存解析记录，不写入学习进度。没有解析到答案时不调用 AI，也不上报空题完成；不确定的最终提交只回查，不自动重发。只有平台目录明确显示“已完成”才记完成。

真实指定小节返回的是 Angular 外壳，单次抓取会得到 0 题；薄适配层按课件配置定位 `data/unit/file.html` 后，交给未修改的上游解析器，已真实取得 **legacy / 5 个填空答案 / 0 次 AI 调用**。早先检查外壳和运行后 DOM 没有 data-solution，不能推导为课件无答案。

接口隔离测试覆盖双模板、动态模板定位、心跳与请求格式、停止不补交、人工开关、空题不提交、结果回查、回执丢失不重交。设置、进度和模块 import 检查已通过。

## 早期已实现（保留代码，默认入口不再调用原生播放 / AI 方案）

- 内置网页登录、课程扫描、平台筛选与独立启停。账号、班级、课程、小节共同构成任务身份。
- 扫描仅读取目录及平台状态；失败保留旧清单。已完成依据是平台目录明确显示“已完成”，分数或本地播放结束不替代完成确认。
- 使用原生课件正常播放，支持隐藏媒体标签对应的可见自定义播放器。停止、异常退出执行器时暂停自己的媒体。
- 可见选择题及单个文本输入控件的 AI 辅助、回填回读、草稿保存。重试复用已答且一致的内容，不覆盖人工更改。
- 文本填空保留人工核对；口语、录音、匹配、排序及未知控件转原网页。当前 WeLearn 草稿保存在独立任务状态中，尚未加入统一“待审答案”的编辑卡片。
- 遵守现有提交设置，结果不明时不重复提交，必须回查原小节完成状态才记为完成。
- 新任务经官方课程信息页进入，避免上次小节的会话导航覆盖 URL；同时核对实际选中的目录项和课件 iframe。等待 AI 期间切换小节将阻止回填。
- WeLearn 启动不依赖学习通登录；混选学习通任务时仍要求学习通就绪。

- 真实后台与界面检查：再次扫描成功，只选指定的一个 WeLearn 小节；未登录学习通时，总开始按钮可用，平台卡片及“准备开始学习”状态正确。未通过这次检查启动课程。

## 已完成的真实接口验收

2026-11-08，用户明确允许仅对独立预览中的指定小节，以不播放视频、等待 30 秒、直接提交 5 题答案及学时 / 完成 / 成绩字段的方式验收。此前的自动审批拒绝在获得这份明确授权后已解除，未扩大到其他小节。

首次尝试在历史记录检查处停止，尚未提交答案。平台返回 ret=0、comment 为空串；原版读取器只将“学习数据不正确”归为未初始化，漏掉了这类成功空记录。新增薄兼容层将成功空记录识别为未初始化，损坏的非空记录仍阻止覆盖；同时保留目录或 CMI 中更大的历史累计时长。

修复后继续同一小节，通过完整接口流程，并额外独立只读核对：

- 原版解析：legacy，5 题。
- 本次等待：30 秒；没有播放视频。
- AI 答题调用：0 次。
- 平台目录：已完成；成绩标签：100。
- 本地任务：done；提交未确认标志：false。
- 已刷新独立预览的真实课程目录。不修改安装版，不打包，不上传。

随后按用户要求，继续从前几个单元抽取多个未完成小节，使用同一平台执行器串行验收，覆盖选择题与不同规模的填空练习。连续执行通过，逐个额外只读核对平台完成、成绩、本地 done 和提交未确认标志，未调用 AI。具体小节和实际记录保存在被忽略的 `.desktop-test/welearn-batch-results.json`，未复制到发布内容。

上述结果证明这些已授权小节的接口流程通过，不代表已完成全部课程类型和长期运行验收。

源码已按用户最新要求复用上游的 SCORM 数据、心跳和写入模块，真实单小节验收已通过。之前的原生练习读取器仍保留，不读取隐藏题解；当前默认执行器直接使用上游题解解析器。

## 代码位置

- `src/platforms/welearn/policy.mjs`：目录、账号与任务身份。
- `api.mjs`、`scan.mjs`：同会话只读扫描。
- `navigation.mjs`：原生入口及实际课件身份校验。
- `practice.mjs`：可见练习、草稿与回填。
- `runner.mjs`：正常播放、辅助作答、原生按钮与平台完成回查。
- `protocol-runner.mjs`：当前默认入口，复用上游流程并回查原小节。
- `preparation.mjs`、`session.mjs`：动态模板薄适配与限定范围的内置会话请求。
- `cmi.mjs`：兼容平台成功返回空历史记录的情况。
- `vendor/auto-welearn/`：上游原始源文件、运行文件、许可证、来源声明。
- `tools/dev/vendor-welearn.mjs`：固定版本运行文件的重建工具。
- `tools/test/test-welearn-protocol.mjs`：当前接口方案的全网络隔离回归。
- `tools/test/test-welearn.mjs`：全网络隔离的浏览器回归。

当前方案直接复用 Auto-WeLearn 的 GPL 实现，出处和许可保存在 vendor 目录。未修改安装版，未打包或上传。
